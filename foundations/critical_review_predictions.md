# Critical Review: DFC Predictions vs. Standard Approaches

**Purpose:** For each DFC prediction, honestly assess whether the Standard Model (or
established effective theories) already produces the same result more simply or more
accurately. Identify where DFC adds genuine value vs. where it replicates known results.

---

## Category 1: Results the SM Already Gets (DFC Replicates)

These predictions match observation, but the SM gets them too — often with better
precision, longer history, or fewer conceptual steps.

| Prediction | DFC | SM | Assessment |
|---|---|---|---|
| M_W, M_Z, Γ_Z | Within 2% | Exact (input params) | SM uses these as inputs; DFC derives them from ECCC scales but needs 2 fitting parameters (M_c(D5), M_c(D6)). DFC adds the claim that these scales come from V(φ), but that chain has T2a gaps. **Verdict: DFC does not improve over SM here.** |
| τ_n (neutron lifetime) | 878.4 s (+0.07%) | 878 ± 1 s (SM + nuclear matrix elements) | Both use G_F and g_A. DFC predicts g_A = 4/π (−0.19%). SM takes g_A from experiment. DFC's value of g_A is a genuine prediction. **Verdict: g_A prediction is genuine; τ_n follows from it.** |
| H_0 | 67.26 km/s/Mpc | 67.4 (Planck ΛCDM fit) | Both use Ω_m, Ω_Λ as inputs. DFC adds no new physics here — it reproduces standard Friedmann cosmology. **Verdict: no added value.** |
| α_em(M_Z) | 1/128.09 | 1/127.95 (measured) | SM measures this; DFC predicts it from 36π. This is a genuine structural prediction — 36π is not an SM result. **Verdict: genuine prediction.** |
| Atomic physics (Rydberg, Bohr, E₁, etc.) | All within 1% | Exact to 12+ digits | DFC just plugs its α into standard QM formulas. The SM + QED gets these to parts-per-trillion. **Verdict: no added value. DFC's α is slightly wrong, making every atomic prediction worse than SM.** |
| Thomson cross-section, Eddington luminosity | Within 0.5% | Exact from QED | Same issue — DFC's α is plugged into standard formulas. **Verdict: no added value.** |
| BBN abundances (Y_p, D/H) | Within 4% | Within 1% (standard BBN) | Standard BBN codes get better precision. DFC uses the same physics with its g_A. **Verdict: g_A = 4/π is the only DFC input; otherwise standard.** |
| CMB first peak, θ_*, r_s | Within 1% | Exact fit (6-param ΛCDM) | Standard cosmology fits these; DFC reproduces them with similar inputs. **Verdict: no added value.** |

## Category 4: Unfalsifiable or Ambiguous Claims

These DFC claims are currently structured so that they cannot be tested or could
accommodate any outcome. **Updated C493** with full T3/T4 audit.

### 4a: Genuinely unfalsifiable (no testable prediction exists)

| Claim | Issue | How to sharpen |
|---|---|---|
| "Space is substrate localization behavior" | Philosophical claim with no measurable difference from GR | Derive a *measurable consequence* that differs from GR at some scale — e.g., a modification to the dispersion relation at Planck energies, or a gravitational decoherence rate |
| Substrate at D1/D2 depths | No observational access; these depths are below all known physics | Identify whether D1/D2 produce any detectable signature. If not, acknowledge as unfalsifiable axiom |
| "Forces are fold interactions of one object" | Ontological framing; predictions are identical to SM gauge theory at all tested energies | Only falsifiable if DFC predicts different high-energy behavior from SM gauge unification. Does it? Currently no |
| Compression as the origin of bifurcation | The claim that self-compression drives bifurcation is structural. No observation distinguishes "compression-caused" from "spontaneous" symmetry breaking | Derive a quantitative consequence of the compression dynamics that SSB alone does not produce |

## Honest Summary

**Where DFC genuinely adds value:**
- Predicting coupling constants (α_em, α_s, g_A, β) that the SM takes as inputs
- Explaining N_c = 3 from multiple independent algebraic conditions
- Resolving the strong CP problem without an axion
- Predicting exactly 3 generations from topology
- Predicting proton stability as exact (not accidental)
- Deriving the light quark mass scale from substrate parameters

**Where DFC is replicating known results with extra steps:**
- All atomic physics (just plugging in a slightly wrong α)
- Standard cosmology (Friedmann equations with SM inputs)
- Electroweak observables (derived from fitting M_c scales, not from first principles)
- BBN (standard BBN + DFC g_A, which is close to measured g_A anyway)

**Where the SM is clearly superior:**
- Any precision observable beyond leading order (g−2, atomic spectra, Z-pole)
- Flavor physics (CKM, PMNS — DFC has almost nothing)
- Anything requiring loop calculations (DFC uses SM loop machinery when needed)

**Key question:** Does DFC's ability to predict ~10 SM free parameters from 2 inputs
(α, β) outweigh its inability to match SM precision in loop calculations? This is the
central value proposition. If the coupling constant predictions are genuine (not circular
or parameter-fitted), then DFC is doing something the SM cannot. If they turn out to
involve hidden fitting, the value collapses.

**Most important test:** Can α_em(0) = 1/137.034 be derived from 36π with zero free
parameters and zero experimental inputs in the running? If yes, this is the single
strongest argument for DFC. If no (if it requires observed hadronic VP as input),
then the claim is weaker than presented.
